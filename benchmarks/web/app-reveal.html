Web app prover benchmark

The web app's own prover modules, as webapp/build.sh ships them (copied here by benchmarks/run.sh --app): the threaded module or the single-thread one, proving the coin reveal or the salted coin reveal. Choose them in this page's address: app-reveal.html?build=wasm-threads&statement=salted-coin-reveal (build: wasm-threads or wasm-single; statement: coin-reveal or salted-coin-reveal). Serve it with serve.py, which makes the page cross-origin isolated, as the threaded module needs.

One session per tab, as on reveal.html: the first proof is the cold run, the rest are warm runs in the same worker. Every proof is checked in the worker by the module before it returns it.
