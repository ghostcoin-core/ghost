Run a Ghost node

Paste one line into a terminal. When it finishes, your node is installed, on the network, syncing and mining. There is nothing else to do.

This is the Ghost public test network. Its coins are test coins with no value, and the network may be reset; if it is, nodes move to the new chain on their own.

macOS and Linux

curl -fsSL https://get.ghostcoin.com | sh

Coming soon: the installer for this system is not published yet.

Use the Ghost web app?

Mines straight to your Ghost wallet, so the coins show up in the web app. Put your wallet address in place of 0xYOUR_WALLET_ADDRESS.

  • macOS and Linuxcurl -fsSL https://get.ghostcoin.com | GHOST_MINE_TO=0xYOUR_WALLET_ADDRESS sh
  • Windows (PowerShell)$env:GHOST_MINE_TO='0xYOUR_WALLET_ADDRESS'; irm https://get.ghostcoin.com/win | iex
